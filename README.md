# Lost and Found Map Mobile App

## Overview
This Android application allows users to report, manage, and locate lost and found items using Google Maps and location-based services.

## Features
- Create, read, update, and delete lost & found items
- Google Maps integration for displaying item locations
- Location autocomplete using Google Places API
- Get current device location
- Radius-based search for nearby items
- Local data persistence using SQLite Database
- Modern and user-friendly interface
- Input validation and error handling

## Technologies Used
- Kotlin
- SQLite Database
- Google Maps SDK
- Google Places API
- Fused Location Provider
- Android Studio
- Material Design Components

## How to Run
1. Open project in Android Studio
2. Add your Google Maps API Key
3. Build and run on emulator or Android device
